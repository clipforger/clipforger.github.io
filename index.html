clipforge uploader

A private desktop tool that uploads and schedules my own edited Shorts to my own YouTube channels (BigMoneyClips and my other clip channels).

This app uses YouTube API Services. By using it you agree to be bound by the YouTube Terms of Service. See also the Google Privacy Policy.

What it does

  • Uploads finished Shorts to my channels as private videos with a scheduled publish time.
  • Reads my own channels' name, ID, view counts, watch time and retention reports, so I can see which edits work.
  • Runs only on my own computer. It is not offered to anyone else and has no other users.
