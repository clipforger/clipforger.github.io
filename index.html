clipforge uploader - Privacy Policy

Last updated: 24 November 2026

clipforge uploader is a private desktop tool used only by its owner to upload and schedule videos to YouTube channels the owner operates (BigMoneyClips and the owner's other clip channels).

What it accesses. With the owner's permission through Google sign-in, it uses the YouTube Data API to upload videos and to read the signed-in channel's name and ID and its own videos' view counts, and the YouTube Analytics API to read the channel's own watch-time and retention reports (scopes: youtube.upload, youtube.readonly, yt-analytics.readonly). It does not access, collect or store data about any other person.

Where data is kept. Sign-in tokens are stored only on the owner's own computer. The tool keeps a local list of uploaded video IDs and their scheduled times. Nothing is sent to any server other than Google's. No data is sold, shared or used for advertising.

Removing access. Access can be revoked at any time at https://myaccount.google.com/permissions, and the local tokens can be deleted from the computer.

YouTube. This tool uses YouTube API Services. By using it you agree to the YouTube Terms of Service. Google's privacy policy: https://policies.google.com/privacy.
