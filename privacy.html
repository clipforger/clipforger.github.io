Privacy Policy

Last updated: 24 November 2026

clipforge uploader ("the app") is a private desktop tool used only by its owner to upload and schedule videos to YouTube channels the owner operates (BigMoneyClips and the owner's other clip channels).

YouTube API Services

The app uses YouTube API Services. By using the app you agree to be bound by the YouTube Terms of Service. Google's handling of data is described in the Google Privacy Policy.

What the app accesses

With the owner's permission through Google sign-in (OAuth 2.0), the app uses:

  • the YouTube Data API to upload videos, and to read the signed-in channel's name and ID and its own videos' view, like and comment counts;
  • the YouTube Analytics API to read the channel's own watch-time and retention reports.

Scopes: youtube.upload, youtube.readonly, yt-analytics.readonly. The app does not access, collect or store data about any other person or any other channel.

How data is used, stored and shared

  • Sign-in tokens are stored only on the owner's own computer.
  • The app keeps a local file with the IDs and scheduled times of uploaded videos, and the latest metrics of the owner's own videos, to compare which edits perform best.
  • Nothing is sent to any server other than Google's. No data is sold, shared, or used for advertising.
  • The app does not use cookies or tracking.

Data retention and deletion

  • Stored metrics are refreshed when the owner runs a report, and any metrics older than 30 days are deleted automatically.
  • Access can be revoked at any time at https://myaccount.google.com/permissions (Google security settings). After revoking, the app can no longer access the account.
  • All locally stored data (tokens, upload list, metrics) can be deleted at any time by deleting the app's data folder; on request to the contact below, it is deleted within 7 days.

Changes

If this policy changes, the date at the top is updated.
